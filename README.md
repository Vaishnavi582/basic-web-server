# GO-MOVIES-CRUD

A simple Go web application for handling HTTP requests, including a form handler and a basic endpoint for greeting users.

## Features

- **Form Handling**: Handles POST requests with form data (`name` and `address`).
- **Static File Server**: Serves static files from a `./static` directory.
- **Hello Endpoint**: Responds to `GET` requests at `/hello`.

## Prerequisites

Ensure you have Go installed on your machine. You can download it from the official site: [Go Downloads](https://golang.org/dl/).



## Endpoints:
- **GET /hello:** Responds with a "hello guyzz!!" message.
- **POST /form:** Handles form submissions with name and address fields.

## Accessing Static Files:
Place your static files in the ./static directory. They will be served at the root endpoint (/).
